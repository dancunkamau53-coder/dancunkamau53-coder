# Advanced Todo Application

A responsive task management application built with HTML, CSS, and JavaScript. This project demonstrates accessible design, persistence, and interactive frontend behavior without external dependencies.

## Features

- Task creation with priority labels
- Persistent storage using local storage
- Active and completed task filtering
- Real-time task statistics
- Accessible controls and keyboard navigation
- Safe text handling with HTML escaping

## Usage

Open `advanced-todo.html` in a modern web browser.

## Notes

This project shows a production-oriented frontend design approach with a focus on usability, maintainability, and accessibility.
