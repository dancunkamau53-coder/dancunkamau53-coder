# Web Development Projects

Interactive web applications showcasing modern HTML5, CSS3, and JavaScript capabilities.

## Projects Included

### 1. Advanced Todo Application (`advanced-todo.html`)

A full-featured task management application demonstrating:

- **Modern UI/UX** - Responsive design with smooth animations
- **LocalStorage API** - Persistent data storage in the browser
- **Priority Levels** - High, Medium, Low task priorities
- **Filtering System** - View all, active, or completed tasks
- **Statistics Dashboard** - Real-time task counters
- **Accessibility** - ARIA labels and keyboard navigation
- **Security** - XSS protection with HTML escaping

#### Features:
✅ Add, complete, and delete tasks
✅ Categorize tasks by priority
✅ Filter tasks by status
✅ View statistics and progress
✅ Persistent storage (survives page refresh)
✅ Responsive mobile design
✅ Keyboard support (Enter to add)
✅ Smooth animations and transitions

#### How to Use:
1. Open `advanced-todo.html` in a web browser
2. Type a task and select priority level
3. Click "Add Task" or press Enter
4. Check off completed tasks
5. Use filter buttons to view specific tasks
6. Tasks are automatically saved

#### Live Features:
- Tasks persist across browser sessions
- Real-time statistics updates
- Visual priority indicators
- Smooth hover and transition effects
- XSS protection for user input
- Improved accessibility with ARIA live regions and keyboard support
