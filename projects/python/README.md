# Data Analyzer

A Python utility for descriptive statistics and outlier detection. The module is designed with clarity, typed interfaces, and reliable behavior for data analysis workflows.

## Features

- Object-oriented design with dataclasses
- Mean, median, standard deviation, and quartile calculations
- Outlier detection using the interquartile range (IQR)
- Graceful handling of empty datasets
- Unit tests for core analysis functions

## Usage

Run the module directly:

```bash
python data_analyzer.py
```

## Testing

Execute the included test suite:

```bash
python -m unittest test_data_analyzer.py
```

## Notes

This project is suitable as a foundation for reporting, preprocessing, or data visualization workflows.
