## Projects Included

### 1. Data Analyzer (`data_analyzer.py`)

A comprehensive statistical analysis tool demonstrating:

- **Object-Oriented Design** - Class-based architecture with dataclasses
- **Statistical Methods** - Mean, median, standard deviation, quartiles
- **Outlier Detection** - Using the IQR (Interquartile Range) method
- **Type Hints** - Modern Python typing for code clarity
- **Documentation** - Docstrings following Google/NumPy conventions

#### Features:
- Calculate descriptive statistics
- Detect statistical outliers
- Generate comprehensive summaries
- Type-safe implementations

#### Usage:
```bash
python data_analyzer.py
```
